# 银行客户洞察报告技能 - 修改指南

## 一、问题诊断

### 你遇到的问题
使用技能生成东莞银行报告时,发现:
- ❌ 表格结构与宁波银行报告不一致
- ❌ 表格行数不固定,有些银行有增减
- ❌ 列结构不统一,表头和列顺序变化
- ❌ 数据缺失时,表格结构被破坏

### 根本原因
原来的模板虽然定义了表格结构,但**没有强制约束AI严格遵守**,导致AI在生成不同银行报告时,根据内容自动调整了表格结构。

### 解决方案
采用**严格固定表格结构**的设计,强制要求:
1. 表头完全固定,不可修改
2. 行数完全固定,不可增减
3. 第1列和最后一列完全固定,不可修改
4. 数据缺失时填写"未披露"或"-",绝对不删除行或列

## 六、常见问题

### Q1:如何确保AI严格遵守固定结构?
A:在模板中使用了以下机制:
1. 在章节开头明确说明"核心原则"
2. 在每张表格上方标注"行固定"和"固定列"
3. 在生成提示词中强调"绝对遵守的原则"
4. 在"禁忌"中明确列出"严禁"的操作
5. 在质量检查清单中提供检查点

### Q2:如果某家银行没有理财子公司,表5的第2行如何处理?
A:按照规则,该行必须保留,填写方式如下:
- 序号:2
- 资质/牌照类型:理财子公司牌照(固定)
- 获取时间:-
- 适用范围:-
- 数据来源:银保监会(固定)

### Q3:如果东莞银行没有上市,表1的第5行如何处理?
A:该行必须保留,填写方式如下:
- 指标项:上市情况(固定)
- 内容:未上市
- 数据来源:年报/交易所(固定)

### Q4:如何批量验证多家银行报告的表格结构一致性?
A:可以使用以下方法:
1. 导出为Word文档
2. 统计每张表格的行数
3. 对比表头和第1列
4. 手工抽查关键表格

### Q5:如果AI仍然不遵守固定结构怎么办?
A:可以尝试以下方法:
1. 在提示词中增加"重复强调":重复多次"表格结构必须完全固定"
2. 在提示词中增加"示例":提供一个严格遵守结构的标准示例
3. 在生成后自动检查:如果发现行数不对,自动提示AI重新生成该表格
4. 人工审核:生成后人工快速检查,发现问题立即反馈
