## 官方数据源清单

### 1. 银行官网（优先级：★★★★★）

**用途**：
- 获取银行基本信息、组织架构、高管信息
- 获取新闻公告、业绩发布信息
- 获取产品介绍、战略方向描述

**关键页面**：
- 关于我们 → 公司简介、组织架构、管理层
- 投资者关系 → 年报、公告、业绩发布会材料
- 新闻中心 → 新闻动态、公告信息
- 产品服务 → 业务板块、产品介绍

**示例银行官网**：
- 宁波银行：https://www.nbcb.com.cn
- 招商银行：https://www.cmbchina.com
- 兴业银行：https://www.cib.com.cn
- 民生银行：https://www.cmbc.com.cn

**数据类型**：
- 基本信息：银行全称、成立时间、注册地、总部
- 组织架构：部门设置、子公司信息
- 高管信息：董事长、行长、副行长等
- 战略信息：战略口号、发展方向

---

### 2. 年度报告（优先级：★★★★★）

**用途**：
- 获取最全面、最权威的财务数据
- 获取业务发展情况、战略目标
- 获取风险管控信息、未来规划

**获取方式**：
- 银行官网 → 投资者关系 → 年度报告
- 上交所/深交所/港交所官网
- Wind金融终端、东方财富网

**关键内容**：
- 财务报表：资产负债表、利润表、现金流量表
- 业务数据：各业务板块营收、客户数、资产规模
- 风险数据：不良贷款率、资本充足率、拨备覆盖率
- 管理层讨论：业务回顾、战略展望、风险分析

**数据示例**：
- 资产总额、负债总额、所有者权益
- 营业收入、净利润、ROE、ROA
- 不良贷款率、拨备覆盖率
- 各业务板块营收占比

**质量标准**：
- 数据权威性：★★★★★
- 数据完整性：★★★★★
- 时效性：年度报告每年3-4月发布

---

**获取数据类型**：

**数据用途**：

## 数据获取方法

### 方法1：直接访问网站获取

**适用场景**：
- 银行官网基本信息
- 年度报告下载
- 监管机构公告

**操作步骤**：
1. 访问目标网站
2. 使用站内搜索功能查找相关页面
3. 下载或复制所需数据
4. 记录数据来源（网站URL、页面标题、访问时间）

**注意事项**：
- 优先使用官方数据源
- 确认数据发布时间，保证时效性
- 截图保存原始页面，以备验证

---

### 方法2：搜索引擎检索

**适用场景**：
- 快速获取特定信息
- 查找相关研报和新闻

**搜索关键词示例**：
- "宁波银行 2025年 年报"
- "宁波银行 不良贷款率 2025"
- "宁波银行 组织架构 2025"
- "宁波银行 战略规划"

**搜索技巧**：
- 使用关键词组合：银行名称 + 数据类型 + 年份
- 使用高级搜索：site:域名 + 关键词
- 限制时间范围：搜索工具 → 时间选择

**注意事项**：
- 验证信息来源可靠性
- 优先选择官方网站和权威媒体
- 避免使用未经证实的第三方信息

---

### 方法3：财经数据库查询

**适用场景**：
- 获取全面的财务数据
- 获取同业对比数据
- 获取历史数据

**操作步骤**：
1. 登录Wind或东方财富网
2. 选择银行板块
3. 筛选目标银行
4. 导出所需数据

**注意事项**：
- 确认数据统计口径一致性
- 注意数据单位（亿元、万元）
- 验证数据异常值

---

### 方法4：人工整合分析

**适用场景**：
- 涉及多源数据整合
- 需要进行数据计算和对比

**操作步骤**：
1. 收集多源数据
2. 验证数据一致性
3. 进行数据清洗
4. 计算衍生指标
5. 记录计算方法和假设

**注意事项**：
- 保持数据来源标注清晰
- 说明数据统计口径
- 标注数据缺失和异常值

## 数据质量标准

### 数据准确性标准

| 数据类型 | 准确性要求 | 验证方法 |
|---------|-----------|---------|
| 基础信息（名称、代码等） | 100%准确 | 与官网、年报交叉验证 |
| 财务数据（营收、利润等） | ≥95%准确 | 以年报为准，与其他数据源对比 |
| 业务数据（客户数、AUM等） | ≥90%准确 | 多源交叉验证 |
| 行业对比数据 | ≥85%准确 | 使用权威数据源，说明统计口径 |

---

### 数据时效性标准

| 数据类型 | 最长可接受时间差 | 推荐数据发布时间 |
|---------|---------------|---------------|
| 年度财务数据 | ≤6个月 | 当年3-4月发布 |
| 季度财务数据 | ≤3个月 | 当季结束后1个月发布 |
| 组织架构信息 | ≤12个月 | 年报或官网最新更新 |
| 战略信息 | ≤12个月 | 年报或业绩发布会材料 |
| 行业基准数据 | ≤12个月 | 年度行业报告 |

---

- [ ] 净息差、成本收入比

- [ ] 2021-2025年趋势数据（至少3年）
- [ ] 同业对比数据（至少2家同业）

### 可选数据项
- 细分业务数据（如各产品线数据）
- 客户结构详细数据

- 历史调整记录

---

### 数据一致性标准

**时间范围一致性**：
- 年度数据必须使用同一会计年度
- 季度数据必须明确标注季度

**统计口径一致性**：
- 对比数据必须使用相同统计口径
- 不同来源数据需说明口径差异

**单位一致性**：
- 金额数据统一使用"亿元"或"万元"
- 比率数据统一使用"%"单位

## 数据来源标注规范

### 标注格式

**标准格式**：
```
来源：[来源名称] [URL] [发布时间]
```

**示例**：
```
来源：宁波银行2025年年度报告 https://www.nbcb.com.cn/ir/2025annual.pdf 2026年3月
来源：Wind金融终端 2025年12月
来源：银保监会公告 http://www.cbirc.gov.cn/xxxx 2025年8月
```

---

### 表格中的标注

**位置**：
- 在表格"补充说明"列标注数据来源
- 如果多个数据项来源不同，在对应行的补充说明列分别标注

**示例**：

| 指标 | 2025年 | 2024年 | 同比变化 | 补充说明 |
|-----|-------|-------|---------|---------|
| 营业收入（亿元） | 500.50 | 450.20 | +11.18% | 来源：宁波银行2025年年度报告 |
| 净利润（亿元） | 180.30 | 165.80 | +8.75% | 来源：宁波银行2025年年度报告 |
| 不良贷款率（%） | 0.95 | 1.02 | -0.07pp | 来源：Wind金融终端 |

---

### 正文中的标注

**位置**：
- 在段落末尾使用括号标注数据来源
- 如果段落包含多个来源，分别标注

**示例**：
```
宁波银行2025年资产总额达到5000亿元，同比增长12.5%（来源：宁波银行2025年年度报告）。
净利润180.3亿元，ROE达到13.5%，高于行业平均水平12.0%（来源：Wind金融终端）。
```

---

### 多源数据标注

**当数据来自多个来源时**：
- 分别标注每个来源
- 说明数据整合方式

**示例**：
```
客户数数据：2023-2024年数据来自宁波银行年报，2025年数据来自Wind金融终端。
```

---

### 估算数据标注

**当使用估算数据时**：
- 明确标注为"估算值"
- 说明估算方法和假设

**示例**：
```
2026年IT预算为预测值，基于2025年IT投入占营收比例3.5%和2026年营收预测550亿元推算。
```

## 数据获取注意事项

### 1. 优先级排序
**数据源优先级**：
1. 银行年报（★★★★★）
2. 银行官网（★★★★★）
3. 监管机构公告（★★★★★）
4. Wind金融终端（★★★★★）
5. 券商研报（★★★★）
6. 财经媒体（★★★）
7. 咨询公司报告（★★★）

---

### 2. 数据时效性管理
**时效性要求**：
- 年度数据：≤6个月
- 季度数据：≤3个月
- 组织架构：≤12个月
- 战略信息：≤12个月

**应对策略**：
- 优先使用最新发布的数据
- 说明数据发布时间
- 如数据过时，在补充说明中标注

---

### 3. 数据完整性保障
**必需数据项**：
- 财务数据：资产、负债、营收、利润
- 风险数据：不良贷款率、资本充足率
- 业务数据：各业务板块营收、占比

**缺失数据处理**：
- 使用"N/A"标注缺失数据
- 说明数据缺失原因
- 尝试从其他数据源补充

---

### 4. 数据一致性控制
**统一标准**：
- 时间范围：统一使用会计年度
- 单位：金额统一为亿元，比率为%
- 统计口径：对比数据口径一致

**差异说明**：
- 不同来源数据存在差异时，说明原因
- 选择最权威的数据源
- 标注数据来源和统计口径

---

### 5. 数据来源记录
**记录要求**：
- 网站URL：完整URL路径
- 文档名称：文档标题、编号
- 发布时间：明确年月
- 访问时间：数据获取日期

**记录方式**：
- 在Excel表格中记录所有数据来源
- 在报告补充说明列标注数据来源
- 保存原始网页截图或文档

## 常见问题

### Q1：不同数据源数据不一致怎么办？
**A**：
1. 优先使用官方数据源（年报、官网）
2. 检查统计口径是否一致
3. 说明数据来源和差异原因
4. 选择最权威的数据源

---

### Q2：数据缺失怎么办？
**A**：
1. 尝试从其他数据源补充
2. 使用"N/A"标注缺失数据
3. 说明数据缺失原因
4. 尝试使用估算值（需明确说明）

---

### Q3：如何判断数据可靠性？
**A**：
1. 检查数据来源权威性（官方 > 权威第三方 > 普通媒体）
2. 检查数据发布时间（越新越好）
3. 与其他数据源交叉验证
4. 检查数据逻辑一致性

---

### Q4：如何获取同业对比数据？
**A**：
1. 使用Wind金融终端
2. 查阅券商研报
3. 参考行业协会报告
4. 手动收集同业银行年报数据

---

### Q5：数据时效性如何保证？
**A**：
1. 优先使用最新发布的数据
2. 定期更新数据（年度数据每年更新）
3. 标注数据发布时间
4. 过时数据需说明原因
