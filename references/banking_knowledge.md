## 专业术语表

### 基础概念

| 术语 | 英文 | 定义 | 备注 |
|-----|------|------|------|
| 资产总额 | Total Assets | 银行在某一特定时点所拥有的全部资产总和 | 包括贷款、投资、现金等 |
| 负债总额 | Total Liabilities | 银行在某一特定时点所承担的全部负债总和 | 包括存款、借款等 |
| 所有者权益 | Owners' Equity | 资产减去负债后的余额，代表银行所有者对银行的索取权 | 也称股东权益 |
| 净息差 | Net Interest Margin (NIM) | 净利息收入与平均生息资产的比率 | 衡量银行核心盈利能力 |
| 成本收入比 | Cost-to-Income Ratio | 业务及管理费与营业收入的比率 | 衡量运营效率 |

### 资产质量指标

| 术语 | 英文 | 定义 | 备注 |
|-----|------|------|------|
| 不良贷款率 | Non-Performing Loan (NPL) Ratio | 不良贷款余额与总贷款余额的比率 | 银行风险控制核心指标 |
| 不良贷款余额 | NPL Balance | 被划分为次级、可疑、损失类的贷款余额 | 监管重点关注 |
| 拨备覆盖率 | Provision Coverage Ratio | 贷款损失准备余额与不良贷款余额的比率 | 衡量风险抵御能力 |
| 拨贷比 | Provision to Loan Ratio | 贷款损失准备余额与总贷款余额的比率 | 风险准备充足性指标 |
| 关注类贷款 | Special Mention Loans | 贷款分类中关注类贷款余额 | 风险预警指标 |
| 次级类贷款 | Substandard Loans | 贷款分类中次级类贷款余额 | 风险较高 |

### 资本充足率指标

| 术语 | 英文 | 定义 | 备注 |
|-----|------|------|------|
| 资本充足率 | Capital Adequacy Ratio (CAR) | 资本净额与风险加权资产的比率 | 巴塞尔协议核心要求 |
| 一级资本充足率 | Tier 1 Capital Ratio | 一级资本净额与风险加权资产的比率 | 核心资本充足性 |
| 核心一级资本充足率 | Core Tier 1 Capital Ratio | 核心一级资本净额与风险加权资产的比率 | 优质资本充足性 |
| 风险加权资产 | Risk-Weighted Assets (RWA) | 按风险权重计算的资产总和 | 资本充足率分母 |

### 盈利能力指标

| 术语 | 英文 | 定义 | 备注 |
|-----|------|------|------|
| 净资产收益率 | Return on Equity (ROE) | 净利润与平均所有者权益的比率 | 股东回报率指标 |
| 总资产收益率 | Return on Assets (ROA) | 净利润与平均总资产的比率 | 资产使用效率指标 |
| 净利息收入 | Net Interest Income | 利息收入减去利息支出 | 银行主要收入来源 |
| 非利息收入 | Non-Interest Income | 手续费、佣金、投资收益等非利息收入 | 收入多元化指标 |
| 手续费及佣金收入 | Fee and Commission Income | 银行提供金融服务收取的费用 | 中间业务收入 |

### 业务结构术语

| 术语 | 英文 | 定义 | 备注 |
|-----|------|------|------|
| 公司业务 | Corporate Banking | 为企业客户提供的金融服务 | 包括对公贷款、贸易融资等 |
| 零售业务 | Retail Banking | 为个人客户提供的金融服务 | 包括个人贷款、财富管理等 |
| 金融市场业务 | Financial Markets Business | 从事投资、交易、同业业务的部门 | 包括同业拆借、债券投资等 |
| 资产管理业务 | Asset Management | 为客户管理资产的业务 | 包括理财产品、基金等 |
| AUM | Assets Under Management | 资产管理规模 | 衡量资管业务规模 |

### 客群分类术语

| 术语 | 定义 | 备注 |
|-----|------|------|
| 大型国企 | 资产规模大、国有控股的企业客户 | 通常为央企或省属国企 |
| 中小企业 | 年销售额和从业人员数在一定规模以下的企业客户 | 中小企业划分标准参照工信部规定 |
| 小微企业 | 规模更小的企业客户 | 包括小微企业和个体工商户 |
| 大众客户 | 资产规模较小的个人客户 | 通常指AUM在50万元以下 |
| 财富客户 | 资产规模中等的个人客户 | 通常指AUM在50-600万元 |
| 私行客户 | 高净值个人客户 | 通常指AUM在600万元以上 |

## 关键指标计算方法

### 同比增长率

**公式**：
```
同比增长率 = (本期数值 - 上年同期数值) / 上年同期数值 × 100%
```

**示例**：
- 2025年营业收入500亿元，2024年450亿元
- 同比增长率 = (500 - 450) / 450 × 100% = +11.11%

### 复合年均增长率（CAGR）

**公式**：
```
CAGR = (期末数值 / 期初数值)^(1/年数) - 1
```

**示例**：
- 2021年资产规模3000亿元，2025年5000亿元，历时4年
- CAGR = (5000 / 3000)^(1/4) - 1 = 13.62%

### 资本充足率

**公式**：
```
资本充足率 = 资本净额 / 风险加权资产 × 100%
```

**说明**：
- 资本净额 = 一级资本 + 二级资本 - 扣减项
- 风险加权资产 = 各类资产 × 风险权重（按巴塞尔协议标准）

### 不良贷款率

**公式**：
```
不良贷款率 = 不良贷款余额 / 总贷款余额 × 100%
```

**说明**：
- 不良贷款包括：次级类、可疑类、损失类
- 总贷款余额包括正常、关注、次级、可疑、损失类

### 拨备覆盖率

**公式**：
```
拨备覆盖率 = 贷款损失准备余额 / 不良贷款余额 × 100%
```

**说明**：
- 贷款损失准备：银行为应对贷款损失计提的准备金
- 监管要求：一般不低于150%

### 净息差（NIM）

**公式**：
```
NIM = (利息收入 - 利息支出) / 平均生息资产 × 100%
```

**说明**：
- 平均生息资产 = (期初生息资产 + 期末生息资产) / 2
- 生息资产包括：贷款、投资、存放同业等

### 成本收入比

**公式**：
```
成本收入比 = 业务及管理费 / 营业收入 × 100%
```

**说明**：
- 业务及管理费包括：人员费用、折旧摊销、业务费用等
- 该指标越低，运营效率越高

### 净资产收益率（ROE）

**公式**：
```
ROE = 净利润 / 平均所有者权益 × 100%
```

**说明**：
- 平均所有者权益 = (期初所有者权益 + 期末所有者权益) / 2
- 衡量股东投资回报率

### 总资产收益率（ROA）

**公式**：
```
ROA = 净利润 / 平均总资产 × 100%
```

**说明**：
- 平均总资产 = (期初总资产 + 期末总资产) / 2
- 衡量资产使用效率

## 分析框架参考

### 银行业五力分析框架

#### 1. 现有竞争者竞争程度
- 分析维度：市场份额集中度、产品差异化、价格竞争
- 关键指标：前三大银行市场份额、同业价格差异
- 数据来源：银行业协会报告、券商研报

#### 2. 新进入者威胁
- 分析维度：牌照壁垒、资本要求、技术壁垒
- 关键指标：新设银行数量、民营银行获批情况
- 数据来源：银保监会公告

#### 3. 替代品威胁
- 分析维度：金融科技、直接融资、其他金融机构
- 关键指标：第三方支付渗透率、直接融资占比
- 数据来源：央行报告、支付清算协会

#### 4. 供应商议价能力
- 分析维度：存款客户、资金来源、科技供应商
- 关键指标：存款集中度、同业负债占比
- 数据来源：银行年报

#### 5. 客户议价能力
- 分析维度：客户集中度、转换成本、信息透明度
- 关键指标：单一客户贷款占比、客户流失率
- 数据来源：银行年报、客户调研

### 业务竞争力分析框架

#### 1. 市场份额分析
- 计算方法：该银行业务规模 / 同类业务市场总规模 × 100%
- 对比维度：全国市场、区域市场、细分市场
- 数据来源：银行业协会、Wind数据库

#### 2. 增长率分析
- 计算方法：业务规模同比增长率
- 对比维度：自身历史、同业平均、行业平均
- 数据来源：银行年报、同业年报

#### 3. 盈利能力分析
- 关键指标：净息差、成本收入比、ROA、ROE
- 对比维度：同业排名、行业平均水平
- 数据来源：银行年报、Wind数据库

#### 4. 风险控制能力分析
- 关键指标：不良贷款率、拨备覆盖率、资本充足率
- 对比维度：监管标准、同业平均水平
- 数据来源：银行年报、银保监会数据

### 数字化转型成熟度评估框架

#### 1. 基础能力
- 评估维度：IT基础设施、数据治理、技术架构
- 关键指标：IT投入占比、数据中心数量、数据资产规模
- 成熟度等级：1-5级

#### 2. 技术应用
- 评估维度：AI应用、区块链、云计算、大数据
- 关键指标：AI应用场景数、云化系统占比、数据驱动决策比例
- 成熟度等级：1-5级

#### 3. 业务渗透
- 评估维度：线上化率、数字化产品占比、客户体验
- 关键指标：手机银行渗透率、线上交易占比、数字化产品数量
- 成熟度等级：1-5级

#### 4. 组织适配
- 评估维度：组织架构、人才队伍、文化氛围
- 关键指标：科技人员占比、敏捷项目数量、数字化转型参与度
- 成熟度等级：1-5级

#### 5. 投入保障
- 评估维度：资金投入、项目管理、绩效评估
- 关键指标：IT预算规模、数字化转型项目数、ROI达成率
- 成熟度等级：1-5级

### 监管要求汇总

#### 资本充足率监管要求（巴塞尔协议III）
- 资本充足率：≥10.5%
- 一级资本充足率：≥8.5%
- 核心一级资本充足率：≥7.5%

#### 资产质量监管要求
- 不良贷款率：监管无明确上限，但过高将引发关注
- 拨备覆盖率：≥150%（监管导向）
- 拨贷比：≥2.5%（部分银行）

#### 流动性监管要求
- 流动性覆盖率（LCR）：≥100%
- 净稳定资金比率（NSFR）：≥100%
- 流动性比例：≥25%
